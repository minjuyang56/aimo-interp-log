## (2) 방향 규약 — '점수 큼 = robust' 가 모든 곳에서 같은가
   위치                                    찾은 줄  대표 줄
   채점기(상류) robust 정의                        0  (없음)
   평가기 AUC (robust 양성)                      4  ttp_eval.py:42 pos, neg = s[y == 1], s[y == 0]
   평가기 null (라벨만 섞음)                        3  ttp_eval.py:96 ys = rng.permutation(y)
   프로브 학습 (y=robust)                        3  build_sub2048_artifacts.py:23 축소·분류기 = StandardScaler → PCA 24 → 로지스틱 L2 `class_weight
   제출 sub2048 (점수>=thr → True)              6  sub2048_lib.py:10 4. 모델별 가중치(StandardScaler → PCA 24 → 로지스틱) 적용 → **모델별 절대 임계 `thr`** 
   제출 ttp (score<=thr → True)               5  ttp_lib.py:279 def h15c_decide(problems, thr=-4.084031):
   제출 h15C/lencal (점수>=thr)                 2  lencal_lib.py:43 return [bool(s >= thr) for s in scores(problems)]

   **규약 표 (코드에서 직접 읽은 것)**
   | 곳 | 양성(=1) | 점수 방향 | True 판정 |
   |---|---|---|---|
   | 채점기 `are_robust` | robust | — | 반환 True = robust |
   | `ttp_eval.auc` | y==1 = robust | 점수 = **−spur** | — |
   | `ttp_eval.loo_acc` | — | spur 낮을수록 robust | `spur <= thr` |
   | `ttp_lib.decide` | — | score_spurious | `score <= thr` → True |
   | `sub2048_lib` | — | 프로브 점수 큼 = robust | `score >= thr` → True |
   | `lencal_lib` / `h15_lib` | — | −log(단어수) 큼 = robust | `score >= thr` → True |
   → **두 규약이 공존한다**: 프로브·길이는 '큼=robust', 섭동 점수는 '큼=spurious'.
     각 평가기가 자기 규약으로 AUC 를 내므로 **부호 혼동은 없다**(아래 (5) 끝단 검사로 확인).

## (5) 끝단 합성 검사 — 라벨을 **알려진 방향**으로 심고 전 경로를 돌린다
   주의: '반대로 심기' 대조는 **고정 부호 점수에만** 쓸 수 있다. 프로브는 학습하는
   분류기라 반대로 심어도 가중치 부호를 뒤집어 맞힌다(그게 정상이다).
   (a) 규약: probe auc_of(큼=robust)=1.000/0.000 · ttp auc(spur 작을수록 robust)=1.000  OK
   (b) 섭동·고정부호 경로: 정방향 AUC 1.000·정확도 1.000 · 반대로 심으면 0.000  OK
   (c) 제출 `ttp_lib.score_one`+임계: 심은 라벨 재현 1.000  OK
   (d) 프로브 실제 경로(d=10 · 3σ 심음): AUC 0.981  OK
   (e) 검정력 측정 — 같은 경로, 차원만 바꿔 심은 신호의 천장을 본다 (판정 아님)
          차원     1.0σ     3.0σ     8.0σ    20.0σ
          10    0.669    0.996    1.000    1.000
          40    0.715    0.873    0.927    0.946
         400    0.515    0.585    0.685    0.696
      → **차원이 실제 규모(수백~수천)면 20σ 신호도 AUC 0.7 을 못 넘는다.**
        이건 버그가 아니라 n=33 에서 PCA24+LR 경로의 **검정력 상한**이다 —
        #77·#ORG-TRAIN 이 0.5~0.6 에 머문 것을 설명하고, 리포트 검정력 절의 근거가 된다.
